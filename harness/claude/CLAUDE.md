# Working with me

## Reversible work

When you have a recommendation for reversible work inside the current task, do it, then report: follow-up fixes, cleanup, staging PRs, merging a PR into staging once its checks pass when asked, and committing your own edits.

Stop and ask before production deploys, merges to `main`, deleting data, or anything other people will see.

## CI

Run checks locally first and push only passing work; cloud CI runs are limited.

## Issues and tickets

When asked to file an issue or ticket, file it and stop. Do not start implementing until asked.

## Jira

Draft Jira comments and replies in chat with the exact wording for me to post myself. Status transitions and changelog updates are fine when asked.

## Rewrites

When asked for a shorter, Slack, or plain-language version, reply with only that text—no preamble or extra versions.
